# Guide développeur

**Statut :** initial — compléter après le premier lot applicatif

## Prérequis visés

- Windows 10/11 64 bits.
- Node.js 22.
- pnpm 12.15.0.
- Git.

Le dépôt utilise pnpm workspaces. Les commandes exactes d'installation, lancement et packaging seront ajoutées avec le squelette Electron/React. Avant toute PR, exécuter tests, typecheck et build. Les changements de schéma doivent inclure migration et tests.
