# Prise en main

## Démarrer

Au premier lancement, une base d'inventaire locale est disponible. La barre latérale mène à Vue d'ensemble, Inventaire, Mes aéronefs, Projets, Mouvements et Administration. En haut, le nom de la base active est affiché; l'indicateur précise « Hors ligne · SQLite local ».

L'application est prévue pour une fenêtre de bureau; la première mouture visuelle a été préparée pour Windows. Les actions de fenêtre se trouvent dans la barre de titre. Le thème clair ou sombre est mémorisé localement dans les préférences de l'application.

## Choisir une base

Dans Administration, ouvrez la gestion des bases pour reprendre la dernière base, ouvrir une base existante, créer une base vide ou importer un fichier SQLite compatible. Les bases sont indépendantes : leurs références, exemplaires, aéronefs, projets et historiques ne sont pas partagés.

## Parcours conseillé

1. Vérifiez le nom de la base active.
2. Ajoutez vos références dans Inventaire.
3. Enregistrez chaque équipement physique comme un exemplaire avec un code unique.
4. Ajoutez vos aéronefs dans Mes aéronefs, puis affectez les équipements utiles.
5. Consultez les disponibilités et les mouvements depuis la vue d'ensemble et Mouvements.
6. Exportez régulièrement une copie SQLite depuis Administration.

Les champs marqués d'un astérisque sont requis. Les photos sont facultatives.
